Install Pygame Zero
with one command

Sets up Pygame and Pygame Zero on Windows, macOS or Linux so you can run games with pgzrun game.py.

Install

You're on a phone or tablet. Open this page on the computer you'll make games on.

  1. Press Start, type PowerShell and open Windows PowerShell. Not "Command Prompt".
  2. Copy this command, paste it into PowerShell (right-click pastes) and press Enter: 
    > irm https://kylerchan.github.io/pygamezero-installer/install.ps1 | iex
  3. Wait for Installation complete!, then close PowerShell and open a new one.
  1. Press ⌘ + Space, type Terminal and press Enter.
  2. Copy this command, paste it into Terminal (⌘ + V) and press Enter: 
    $ curl -fsSL https://kylerchan.github.io/pygamezero-installer/install.sh | bash
  3. Wait for Installation complete!, then close Terminal and open a new window.
  1. Open a terminal (on Ubuntu: Ctrl + Alt + T).
  2. Copy this command, paste it (Ctrl + Shift + V) and press Enter: 
    $ curl -fsSL https://kylerchan.github.io/pygamezero-installer/install.sh | bash
  3. Wait for Installation complete!, then close the terminal and open a new one.

Need Python? The installer finds a suitable Python (3.9–3.13) on its own. If you don't have one, it tells you exactly what to do, and on Windows and macOS it can install Python for you after asking. It never needs administrator rights or your password.

Make your first game

Make a folder called my-game. Inside it, create a file called game.py with this code:

WIDTH = 500
HEIGHT = 400

x = 0

def draw():
    screen.fill((30, 30, 60))
    screen.draw.filled_circle((x, 200), 30, "orange")
    screen.draw.text("Hello, Pygame Zero!", (20, 20), fontsize=40)

def update():
    global x
    x = (x + 3) % WIDTH

Then, in a new terminal, go into the folder and run it:

cd my-game
pgzrun game.py

A window opens with a moving orange ball. Put pictures in an images folder and sounds in a sounds folder next to game.py. Next, try the official Pygame Zero tutorial.

Help

"pgzrun" is not recognized / command not found

Close the terminal and open a new one: old windows don't see the new command. Still stuck? Run the install command again and read the last lines it prints.

"No compatible Python found" or "Python 3.14 is too new"

Pygame doesn't support Python 3.14 yet. Install Python 3.13 with the command the installer shows (you can keep your other Python), open a new terminal and run the installer again.

Windows: winget install --id Python.Python.3.13 -e --scope user
macOS: brew install python@3.13, or download it from python.org.

"Could not download packages"

You're offline, or the network blocks pypi.org. Try another network (for example at home), or ask IT to allow pypi.org and files.pythonhosted.org.

"Virtual environment support is missing" (Ubuntu / Debian)

Run the sudo apt install python3.X-venv command the installer prints, then run the installer again.

"Permission denied"

Close any running games and code editors and try again. Don't use sudo or "Run as administrator".

Using VS Code, Thonny or Mu

At the end, the installer prints "Python for your editor" followed by a path. Choose that Python as the interpreter in your editor.

Uninstall

macOS / Linux:

curl -fsSL https://kylerchan.github.io/pygamezero-installer/install.sh | bash -s -- --uninstall

Windows (PowerShell):

& ([scriptblock]::Create((irm https://kylerchan.github.io/pygamezero-installer/install.ps1))) -Uninstall

This removes only what the installer added. Your games and other Python installations stay.

Is this safe?

The command downloads a small script and runs it. Before running anything else, the script checks that the main installer file matches a fixed SHA-256 fingerprint from a tagged release. It installs only into your own user folders, never asks for a password, and never changes your other Python installations.

Prefer to read the code first? Everything is on GitHub, including how to download and inspect it before running.
